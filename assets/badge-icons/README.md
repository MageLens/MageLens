# Badge icons

PHP, JavaScript, HTML5 and Cypress SVGs are vendored from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/d0b3c2d7153794b912913746fc0498a5d3211727/icons)
at revision `d0b3c2d7153794b912913746fc0498a5d3211727` under the included [CC0 license](LICENSE.md).

The [badge generator](../../bin/badges.cjs) embeds their paths directly into each output SVG.
